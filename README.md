# MailSprite

MailSprite is a lightweight Windows 11 tray application for playful, IncrediMail-inspired email arrival animations, designed to coexist with Mailbird.

**Prototype status:** Animation preview works independently of mail access. Mailbird alert detection is experimental and disabled by default; it uses accessibility window-open events, not passwords or email account access. Support depends on how Mailbird displays notifications on your Windows system.

See the latest GitHub Actions build artifact for a Windows x64 executable once the project build completes.
